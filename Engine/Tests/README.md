# 航线校验

这些检查使用 macOS 随 Xcode 或 Command Line Tools 提供的 Swift 编译器。测试在系统临时目录中编译，退出时清理。测试存档保存在内存中。

```sh
./verify.sh
./verify.sh --optimal
./verify.sh --charts 4096
./verify.sh --long-charts
```

常规检查会重放十二份邮件，撤回每条参考航迹上的每一步，检查存档复原、潮限和水闸。它还从偏航、候拍或提前留影后的状态跟随领航提示，直至投递成功。

`--optimal` 将所有船放在同一时间轴上前进。每艘活动中的船每拍付出一次移动成本，已录完的船影则留在末格。搜索保留位置、邮戳和停船状态，并用全闸开启时的最短剩余航程剪枝。两张已知有更短解的测试图会先检查搜索结果和回放，再核对十二关的最短总拍。

`--charts 4096` 根据连续种子和固定随机种子抽验外海航图。它检查八种题型、可达性、电码校验符、参考解、存储后重开以及按提示投递。

`--long-charts` 默认走查 32,768 个不同航码，每种题型各 4,096 张。每张航图都在偏离参考航线后保存到 JSON，再凭航码和指令历史恢复。逐项比较五种航行输入、留影返航与撤回的结果。每组题型都抽查最少船影数和恢复后的领航提示。另取两组航图独立计算最优拍数，回放搜索发现的更短解。该模式降低进程优先级，每批计算后让出处理器。可用 `./verify.sh --long-charts 512` 运行较小的一轮。

版本 M1 的八份固定样例覆盖全部题型，锁定版图、潮限、参考解和航码。运行 `./verify.sh --vectors` 可以打印这些样例的指纹。
