# 雾信航局 · MIST POST

[下载 macOS 游戏](https://github.com/MMMforY/mist-post/releases/download/v1.0/MistPost-macOS.dmg) · [23 秒实机演示](https://github.com/MMMforY/mist-post/releases/download/v1.0/MistPost-Gameplay.mp4)

一款中文单人回合制航海解谜游戏。你驾驶邮船，把盐田、船坞与远灯群岛居民的十二封信送到收信灯塔。每走一格，海上就过去一拍。

## 第一趟航行

打开「雾信航局.app」，选择「启程送信」。用方向键沿海图上的虚线水道行驶，也可以点击与船身相邻的水格。第一封信只需要绕过浅滩抵达灯塔。你可以随时离开游戏，下次启航会续接已保存的航程。

第二条航路会遇到水闸。先驶上与闸门同号的铃标，然后按 **E** 留影返航。回到出发港后，上一程的船影会逐拍重走原路，抵达末格时会停留。船影在铃标上的那一拍，你可以驶入对应水闸。海图中的闸臂提前显示下一拍能否通行。

「航员手册」第二页有一段可逐拍操作的演练，可以独立练习两趟航程的配合。

| 控制 | 操作 |
| --- | --- |
| 方向键或 WASD | 向四个方向航行一格 |
| 空格或点击船身 | 原地候一拍 |
| E 或回车 | 将这一程留作船影，返回出发港 |
| Z 或退格 | 撤回一步，也能撤回刚刚录下的船影 |
| H | 查看当前局面的一步领航提示 |
| R | 打开重航确认 |
| ? / M / Esc | 打开手册、切换声音、关闭面板或返回 |
| Tab、Shift-Tab、回车 | 选择并操作界面控件 |

点选潮表可预览指定节拍的船影与闸门。按 1、2、3 或点击邮单上的「查铃」号码，可同时标出同号铃标和水闸，读出它们的坐标和开闸时段。右键也可检查船边的航标。需要盖戳的信件，必须在最后实际投递的那一程访问所有邮戳站。本船与船影可以占用同一水格。每条航线的总拍数包含各趟航程的移动与候潮。

## 航路、信件与海图

- **群岛航路簿**有三个航区、十二个港口。到达灯塔后拆信、收取邮票，逐港开启新航线。达到该关最短总拍可获得准点戳。
- **收信册**保存已收到的信与最佳航迹。回放中可点击「第几程」及下方潮拍，直接回看某艘船影留在铃标上的那一刻。左右键逐步回放，上下键切换航程，V 键或「速度」按钮可在 1×、2×、0.5× 之间切换。也可印制 2400 × 1500 像素的 PNG 明信片。收齐十二封后，从收信册右下角选择「重读结航回函」，可再次阅读总局来信、印制全港邮路图。回函里还附有三张港民亲绘的加班航线，收图后可在海图匣试航、导出或改绘。
- **电报台**在送完盐风外港的四封信后开通。可接收本地日期对应的每日航线或随机航线。凭相同的 M1 电码即可离线重建同一张图。电报上的参考航程由实际可行的航迹生成。送达后可印制带有电码、海图和个人最佳航迹的明信片。日后从「最近航件」选中这封电报即可补印。
- **制图室**位于航路簿下方。可画水域、陆地、港口、邮戳站及三组铃闸，编辑署名、回信、船影上限和潮限。草图会自动保存。亲自走通后，海图匣可导出含作者航迹的 `.mistchart` 文件。文件可以在另一台安装了游戏的 Mac 上打开。海图匣中附有示范海图《潮桥手记》。

游戏提供高对比海图、减少动态、航迹开关、静音与 VoiceOver 操作。听觉上三组铃分别敲一、二、三声，海图上同时使用号码与形状标识。存档位于 `~/Library/Application Support/MistPost/`。

## 从源码构建

在安装了 Xcode 或对应命令行工具的 Mac 上，从本目录运行。开发验证环境为 Apple Silicon、Xcode 27.1 和 Apple Swift 6.4，构建使用 Swift 5 语言模式及系统框架。部署目标为 macOS 13 或更新版本。

```sh
./build.sh
open "build/雾信航局.app"
```

构建 Apple Silicon 和 Intel 双架构应用可运行 `./build.sh universal`。应用在本机完成 ad-hoc 签名。源码和运行资源都已包含在本目录中。执行 `Tools/package-macos.sh "build/雾信航局.app" "雾信航局.dmg"` 可制作用来拷贝安装的只读磁盘映像。

## 工程与验证

`Engine/` 保存确定性的回合规则、主线关卡、领航求解器和 M1 航图生成器。`WorkshopModel/` 负责草图、撤回、成图指纹和导入时的试航复核。`Chart/` 绘制动态海图，`Audio/` 合成海浪、雾号与航行音乐。`App/` 包含界面、存档、无障碍导航和印刷输出。`Resources/` 保存画面原稿的运行版本、程序图标和示范海图。

运行 `./verify.sh` 可检查玩法、渲染、音频、工坊、原生界面和存档。测试使用独立临时文件。原生无障碍检查会操作 AppKit 控件。系统拒绝跨进程无障碍查询时，测试会标明该项已跳过。另可执行 `Checks/verify-documents.sh "build/雾信航局.app"`，通过 macOS 文档服务验证冷启动和运行中打开自制海图。更大规模的固定种子验证可单独运行 `Engine/Tests/verify.sh --long-charts --optimal`。主线参考解记录在 `Engine/Solutions.md`，其中包含谜题答案。
