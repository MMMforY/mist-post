# 制图室校验

在此目录运行 `./verify.sh`。脚本使用系统 Swift 编译器，在临时目录构建独立校验程序。用例覆盖三种图幅、港口移动与交换、两枚邮戳的上限、设置的原子提交、调整图幅后撤回、撤回历史持久化，以及草图和成图各自的文件格式。

`Fixtures/tide-bridge.mistchart` 是一份可直接导入的版本 1 成图。两艘船影分别驻守北岸和南岸的铃标，送信船要在七拍内经过两座邮戳站，再驶入灯塔。固定档案检验航迹以及跨版本保留的内容标识。

五千次固定种子的编辑操作会反复绘制、改名额、调整图幅、撤回和重开草图。可直接送达的样本会另行封存和导入，核对同一份文件的内容标识。输入校验覆盖缺失港口、重复港口、错误图幅、未知地形、越界潮限、空航迹、超时航迹、未送达试航和未知格式版本。
